## Tools

### Password Generator

Generate secure random passwords using:

* Uppercase and lowercase letters
* Numbers
* Symbols

Features:

* Secure randomness
* Customizable length (planned)
* More options coming soon

Example:

```bash
Password length: 16

Generated password:
A@8mQ#2xLp!3Tz&
```

## Run Locally

Clone the project:

```bash
git clone https://github.com/iamrudrobala/mini-tools.git
```

Go to the project folder:

```bash
cd mini-tools
```

Run:

```bash
python passGen.py
```
