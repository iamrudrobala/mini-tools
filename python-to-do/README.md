# 📝 Python To-Do App

A simple command-line To-Do application written in Python. This project allows users to manage their daily tasks by adding, viewing, and removing items from a task list.

## Features

* ✅ Add new tasks
* 📋 View all tasks
* 🗑️ Remove completed or unwanted tasks
* 🚪 Exit the application safely
* 💻 Beginner-friendly and easy to understand

## Requirements

* Python 3.7 or later

## Installation

1. Clone this repository:

```bash
git clone https://github.com/your-username/python-todo-app.git
```

2. Navigate to the project folder:

```bash
cd python-todo-app
```

3. Run the application:

```bash
python todo_app.py
```
